# Roadmap

Ordered milestones of the terminal revamp, epic [#36](https://github.com/pascalallen/pascalallen.com/issues/36). Status lives in the epic and `docs/build-log.md`.

1. [#37](https://github.com/pascalallen/pascalallen.com/issues/37) Claude Code setup, CI and project docs.
2. [#38](https://github.com/pascalallen/pascalallen.com/issues/38) Remove auth, users, Postgres, RabbitMQ and the React SPA.
3. [#39](https://github.com/pascalallen/pascalallen.com/issues/39) Shell core and content as a pure Go domain package.
4. [#40](https://github.com/pascalallen/pascalallen.com/issues/40) Server-side repository and package feeds, visit ping, synchronous buses.
5. [#41](https://github.com/pascalallen/pascalallen.com/issues/41) Move the camera hub to infrastructure and degrade gracefully.
6. [#42](https://github.com/pascalallen/pascalallen.com/issues/42) Multi-arch Docker build, Pi compose overlay, working cron deploy.
7. [#43](https://github.com/pascalallen/pascalallen.com/issues/43) WebAssembly bridge, toolchain choice and size budget.
8. [#44](https://github.com/pascalallen/pascalallen.com/issues/44) TypeScript terminal host and visual design.
9. [#45](https://github.com/pascalallen/pascalallen.com/issues/45) Server pre-render, SEO and no-JS content.
10. [#46](https://github.com/pascalallen/pascalallen.com/issues/46) Live commands end to end and browser e2e suite.
11. [#47](https://github.com/pascalallen/pascalallen.com/issues/47) Cleanup sweep, README and prose rules replaced by checks.
